# MCP Registry Submission

How to get this plugin listed on MCP directories.

## modelcontextprotocol.io (official registry)

The official MCP server registry accepts server submissions. This plugin qualifies as a community contribution.

1. Go to https://github.com/modelcontextprotocol/servers
2. Fork the repo
3. Add an entry to the appropriate section (likely "Analytics" or "Product"):
```json
{
  "name": "Fullstory Skills Plugin",
  "description": "44 AI skills for Fullstory product analytics — frustration analysis, funnel optimization, error debugging, A/B testing, retention, accessibility, and more. Installs as a Claude Code/Cursor plugin.",
  "url": "https://github.com/reatlat/fullstory-claude-plugin",
  "tags": ["fullstory", "analytics", "product", "ux", "session-replay"]
}
```
4. Open a PR

## mcpservers.org (community directory)

1. Go to https://mcpservers.org
2. Click "Submit a server"
3. Fill in:
   - Name: "Fullstory Skills Plugin"
   - URL: https://github.com/reatlat/fullstory-claude-plugin
   - Description: "44 AI skills for Fullstory product analytics — frustration analysis, funnel optimization, error debugging, A/B testing, retention, and more."
   - Category: "Analytics"
   - Tags: fullstory, analytics, claude, product-analytics, session-replay

## smithery.ai

1. Go to https://smithery.ai
2. Search for "Fullstory" — if not listed, submit via their directory form
3. Link to the GitHub repo

## pulsemcp.com

1. Go to https://pulsemcp.com
2. Submit via their "Add Server" flow
3. Link: https://github.com/reatlat/fullstory-claude-plugin
